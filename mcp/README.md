# vim_rs MCP Server

A Model Context Protocol (MCP) server for the vSphere API, providing AI assistants with access to comprehensive vSphere API documentation and search capabilities.

## What is MCP?

The Model Context Protocol (MCP) is an open protocol that standardizes how applications provide context to LLMs. This server makes the vim_rs vSphere API documentation searchable and accessible to AI coding assistants.

## Quick Start

### Build the Server

```bash
cd mcp
cargo build --release
```

### Test the Server

```bash
# Run the server (it communicates via stdio)
cargo run

# Or use the release binary
./target/release/vim_mcp_server
```

### Example Interaction

The server uses JSON-RPC 2.0 over stdin/stdout. Here's a manual test:

```bash
# Initialize
echo '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}' | cargo run

# List tools
echo '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | cargo run

# Call the hello tool
echo '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"hello","arguments":{"name":"vSphere"}}}' | cargo run

# Get stats
echo '{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"stats","arguments":{}}}' | cargo run

# List resources
echo '{"jsonrpc":"2.0","id":5,"method":"resources/list"}' | cargo run

# Read metadata resource
echo '{"jsonrpc":"2.0","id":6,"method":"resources/read","params":{"uri":"vim://metadata"}}' | cargo run
```

## Current Features (v0.1.0)

**Tools:**
- `hello` - A simple greeting tool (demo)
- `stats` - Returns vSphere API statistics

**Resources:**
- `vim://metadata` - Access to API metadata

## Architecture

```
mcp/
├── src/
│   └── main.rs          # MCP server implementation
├── data/                # Generated JSON data
│   ├── managed_objects.json    (2.9 MB - 184 objects, 2,195 methods)
│   ├── data_structures.json    (8.0 MB - 3,890 structures)
│   ├── enumerations.json       (1.0 MB - 623 enums)
│   └── metadata.json           (566 bytes)
└── docs/                # Design documentation
```

## Data Generation

The JSON data is generated by `vim_build`:

```bash
cd vim_build
cargo run --release
```

This generates MCP-ready JSON files in `../mcp/data/`:
- **managed_objects.json**: All vSphere managed objects with methods and signatures
- **data_structures.json**: All data structures including pruned types (Event, MethodFault)
- **enumerations.json**: All enum types with variants
- **metadata.json**: Statistics and generation info

## MCP Integration

To use this server with an MCP client (like Claude Desktop):

1. Build the release binary
2. Add to your MCP client configuration
3. The server will be available as a tool provider

Example configuration:
```json
{
  "mcpServers": {
    "vim-mcp": {
      "command": "/path/to/vim_mcp_server",
      "args": []
    }
  }
}
```
